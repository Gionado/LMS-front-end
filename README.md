# Learning With Us Student LMS

Frontend prototype for the Learning With Us student learning portal.

## Features

- Demo student login
- Learning dashboard and weekly progress
- Searchable and filterable courses
- Course details and learning modules
- Ebook library with simulated downloads
- Responsive purchase history table
- Mobile and desktop navigation

## Tech stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Lucide React

## Getting started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
